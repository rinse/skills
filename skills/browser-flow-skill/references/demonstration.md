# ユーザーの実演を codegen で記録する

ユーザーが自分で操作して見せるときの手順。
playwright codegen が開くブラウザでの操作を、locator 付きのコードとして記録する。

## 画面か対話が無ければ実演を諦める

Subagent の中などユーザーに尋ねられない場面や、ディスプレイの無い環境（SSH 越し、CI など）では、実演を記録できない。エージェントの操作で取り込むことを提案する。

## 先にログインを済ませ記録に入れない

対象がログインを要するなら、codegen を開く前に playwright-cli-auth スキルに従ってログインし、ログイン後のページを確かめたうえで状態ファイルに書き出す。

```bash
playwright-cli state-save "<セッションの一時領域>/auth.json"
```

この状態ファイルを codegen に渡すと、記録はログイン済みの画面から始まり、ログインの入力が記録に入らない。

## codegen を開いて操作してもらう

```bash
npx playwright codegen --target=javascript \
  --load-storage="<セッションの一時領域>/auth.json" \
  -o "<セッションの一時領域>/recording.js" \
  '<起点 URL>'
```

- codegen はユーザーがウィンドウを閉じるまで終わらないので、バックグラウンドで実行する。
- ログインが要らなければ `--load-storage` を外す。
- `npx playwright` が取得できなければ、playwright-cli に同梱の playwright-core を使う（`node "$(npm root -g)/@playwright/cli/node_modules/playwright-core/cli.js" codegen ...`）。
- `Executable doesn't exist` で失敗したら、Playwright 同梱のブラウザが入っていない。`--channel=chrome` を足してシステムの Chrome で開く。

依頼する文面には次を含める。

- 目的の操作を最後まで行い、終わったらブラウザのウィンドウを閉じて報告すること。
- ログイン画面が出たら、何も入力せずにウィンドウを閉じて報告すること。その場合は playwright-cli-auth でログインし直し、状態ファイルを上書きしてから codegen を開き直す。
- 送信や購入のような取り消せない操作を実際に行うかはユーザーが決めること。行わない場合は、どの要素を押す操作かを言葉で伝えてもらう。

報告を受けるまで、エージェントはブラウザを操作しない。

## 資格情報を読まずに記録を開く

codegen は入力した値を `.fill('<値>')` の形で平文のまま記録する。ログインの入力を含む記録を読むと、資格情報がエージェントの文脈に入り、生成 AI を運用する企業へ送られる。

- ログイン画面で入力したとユーザーが報告したら、`recording.js` を読まずに削除し、ログインし直してから撮り直す。会話の外でも入力した資格情報は変更するよう勧める。
- 報告が無くても、読む前に件数だけを出してログインの痕跡を探す。

    ```bash
    grep -c -i -E 'passw|\bpass\b|\bpwd\b|パスワード|暗証|ワンタイム|one.?time|\botp\b|2fa|認証コード' "<セッションの一時領域>/recording.js"
    ```

    1 件以上なら、同じく読まずに削除して撮り直し、ログインの入力が記録されていた可能性を伝えて資格情報の変更を勧める。該当する行だけを消しても、ログイン ID のようにこの語を含まない入力が前後に残る。

撮り直しは、ログイン画面で閉じた場合も含めて 1 回までにする。2 回目もログイン画面が出るか検査に該当すれば、目的の操作そのものがログインやパスワードを扱う画面を通る可能性がある。記録を安全に読めないことを伝え、エージェントの操作での取り込みを提案して止まる。

## 記録を手順に組み立て直す

`recording.js` を読み、SKILL.md の「手順には目的に要る操作だけを残す」以降に沿って組み立て直す。記録をそのまま生成するスキルのスクリプトにしない。

## 状態ファイルと記録を消す

生成したスキルの検証を終えたら、途中で止まるときも含めて `auth.json` と `recording.js` を削除する。状態ファイルはセッションを、記録は入力した値を含む。
