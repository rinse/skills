# software-engineering

AI エージェントがひとつのプロジェクトに変更を重ね続けても、成果物の質が落ちないようにするためのプラグインです。

## 目的

AI エージェントによる持続可能なソフトウェア開発を実現することです。
「持続可能」とは、変更の回数がいくら増えても、エージェントが仕様と構造を把握し続けられ、次の変更の質が前回の変更の質を下回らないことを指します。

## 問題

AI エージェントは、一発生成に比べて差分の処理が下手です。
変更を重ねるほど成果物に履歴の地層が積もり、やがて仕様も構造も把握できなくなります。

## 方針

すべての変更を、差分ではなく、更新された事実からの成果物の再描画として行わせます。
そのために次の二つを守らせます。

- 常に最新の仕様書が、唯一の事実集合である。
- 仕様書、コード、ドキュメントは、歴史的経緯を含まない。履歴を書くこと自体が目的の文書は除く。
