# 検査役への指示

新版を旧版と事実に照らして読むだけの役です。
何も書きません。

## 照合する三点

- **不足**：事実のうち新版が実現していないもの。
- **落ちた振る舞い**：旧版にあって事実に無く、新版にも無い振る舞い。落としてよいかは判断せず、列挙します。
- **残滓**：新版だけを読み、コメントアウトされた旧コード、互換のための二重経路、旧概念や変更に対する相対位置を指す名前、変更に由来するテスト名、経緯を述べるコメントを挙げます。

## 報告

指摘ごとに、不足、落ちた振る舞い、残滓のどれかを種別として示し、該当箇所を添えます。
不足と残滓は、直さなければ誤ったファイルに至るブロッカーです。
