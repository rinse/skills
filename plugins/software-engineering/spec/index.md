# software-engineering 仕様書

## 目的

software-engineering は、AI エージェントがプロジェクトを持続的に開発するためのプラグインです。

## 概要

AI エージェントは、初回の出力に比べて差分の出力が苦手です。
変更を頼まれたエージェントのコンテキストには、古い成果物と変更指示と変更理由が同時に載ります。
この条件で最も出やすい出力は「何が真か」と「何が変わったか」を同時に述べる文やコードで、旧状態の否定、変更の経緯、コメントアウトされた旧コードとして成果物に残ります。
変更を重ねるほど成果物に履歴の地層が積もり、仕様は仕様書と会話とコードの但し書きに散り、構造は足された例外で読み取れなくなります。
エージェントは把握できない仕様と構造に対して変更を加えることになり、変更の質はさらに落ちます。

このプラグインは、変更を差分ではなく、事実集合の更新と、更新された事実からの成果物の再描画として行わせます。
一つの変更は、種から仕様書を起こす段と、仕様書から成果物を描く段の二段で進みます。
ユーザーが書くのは種だけで、了承するのは仕様書の差分です。

## 仕様書

- [common.md](common.md)：不変条件、用語、検査と停止、構造表、配布と書き方。
- [spec.md](spec.md)：種から仕様書を起こす流れと、仕様書の規範。
- [redraw.md](redraw.md)：仕様書から成果物を描く流れと、三役。
